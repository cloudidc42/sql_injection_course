## เกี่ยวกับหลักสูตรนี้

หลักสูตรนี้ครอบคลุมการเรียนรู้ SQL Injection และ Database Exploitation อย่างครบวงจร ตั้งแต่พื้นฐาน SQL ไปจนถึงเทคนิคระดับโลกที่ใช้ใน Bug Bounty, CTF, และงาน Penetration Testing

### ระดับหลักสูตร
- **ระดับ 1-200:** พื้นฐาน (Beginner)
- **ระดับ 201-400:** กลาง (Intermediate)  
- **ระดับ 401-600:** สูง (Advanced)
- **ระดับ 601-800:** ผู้เชี่ยวชาญ (Expert)
- **ระดับ 801-1000:** ระดับโลก (World-class)

    image: webgoat/webgoat-8.0

      - "8081:8080"

    image: mysql:5.7
    environment:
      MYSQL_ROOT_PASSWORD: rootpass
      MYSQL_DATABASE: testdb
    ports:
      - "3306:3306"

## คำเตือนทางกฎหมาย (Legal Warning)

```
การทดสอบ SQL Injection บนระบบที่ไม่ได้รับอนุญาตถือเป็น:
- ความผิดทางอาญาในประเทศส่วนใหญ่
- ผิดพระราชบัญญัติว่าด้วยการกระทำความผิดเกี่ยวกับคอมพิวเตอร์ พ.ศ. 2550
  (และที่แก้ไขเพิ่มเติม พ.ศ. 2560)

ทดสอบเฉพาะกับ:
✓ ระบบของตัวเอง
✓ ระบบที่ได้รับอนุญาตเป็นลายลักษณ์อักษร
✓ Lab environments ที่ออกแบบมาสำหรับการทดสอบ
✓ CTF challenges ที่เปิดให้เข้าร่วม
✓ Bug Bounty programs ที่ระบุชัดเจนว่าอนุญาต
```
